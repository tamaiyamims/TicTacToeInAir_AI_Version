# Tic Tac Toe in Air - AI Version

COS 460 project.

This project combines:
1. Tic Tac Toe game logic with an AI opponent.
2. MediaPipe hand tracking for playing the game in the air.

## How it works
- The camera detects the player's hand.
- The index finger points at a square.
- Holding the finger over an empty square makes an X.
- The AI automatically makes an O move.
- The game checks for a win, loss, or draw.
- Restart Game starts a new game.

## Files
- index.html
- styles.css
- script.js
- README.txt

## How to run
Use GitHub Pages or another HTTPS web server.
Allow camera access when asked.

## Controls
Point at a square and hold your finger there briefly.
